# time7-selector

Uma telinha onde você escolhe um personagem e o site muda de cor baseado nele :)

Fiz esse projeto pra treinar JavaScript junto com CSS, principalmente trocar tema sem recarregar a página e lembrar a escolha depois.

## O que acontece

- você clica em um personagem
- o visual da página muda
- a escolha fica salva no navegador
- quando abre de novo, continua igual

## Tecnologias
HTML • CSS • JavaScript
